# Ancient Greek scan

Ancient Greek is an optional downstream detector, never an input to EXNIHILO generation.

The detector must document the exact Unicode normalization and lexical source used. Historical Greek has multiple orthographies and diacritic conventions, so a match should preserve the original generated bytes and the normalized representation used for detection.

A short Ancient Greek word appearing in a huge random dataset is not by itself remarkable. Rank results by sequence length, rarity, and the number of independent opportunities searched.

If a long coherent sequence appears, preserve the complete raw dataset and its cryptographic hash before interpretation.
